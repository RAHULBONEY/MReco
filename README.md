

# 🎧 MReco - Music Recommendation Web App

MReco is a full-stack music recommendation app that helps users discover songs based on their preferences. It includes a sleek dark UI, real-time song playback, a single-user playlist, and heart-based liking features to personalize recommendations.

## 🛠 Tech Stack

- **Frontend**: React.js, Material-UI
- **Backend**: Node.js, Express.js
- **Authentication & DB**: Firebase Auth, Firestore
- **Music Recommendation**: Basic ML filtering logic
- **Styling**: Custom CSS + MUI
- **Hosting**: Vercel / Firebase Hosting

---

## 🔑 Features

- 🎵 Recommends songs based on liked music
- ❤️ Heart button to like songs and update recommendations
- 💾 Persistent playlist for logged-in users
- 🔐 Firebase-based user authentication
- 🎧 In-app music player
- 🌙 Modern, responsive dark UI

---

## 🧠 How It Works

1. User logs in using Firebase Auth.
2. Song likes are tracked and stored in Firestore.
3. A recommendation algorithm (simple collaborative filtering or similarity-based) picks relevant songs.
4. All songs are played within the app using a custom player.
5. UI reflects real-time playlist and liked items.
